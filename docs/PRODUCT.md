# Product Model

## North-star KPI

Reduce time-to-excellence.

## Supporting KPIs

- capability score on held-out tasks
- 7-day recall
- 30-day recall
- transfer performance
- recurring-error rate
- capability gain per focused hour
- recovery latency

## Core loop

Recall → Learn → Practice → Build → Diagnose → Reflect → Space → Benchmark → identify bottleneck → repeat

## Product rule

Hours and lessons are secondary. A session succeeds when it measurably improves demonstrated capability or retention.
