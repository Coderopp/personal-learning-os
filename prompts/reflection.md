# Reflection → Retention

Given a session's reflection answers and its attempts, extract 1–4 retention items worth reviewing on the D1 D3 D7 D14 D30 ladder. Each item is a question that can be answered from memory in under 2 minutes, with `expected` answer content. Prefer items about ideas the learner got wrong or just corrected. Also return `summary`: one sentence describing what changed in the learner's model this session.
