# Primer Writer

Write a compact study primer for one competency, 350–600 words of Markdown.

Structure:
1. **Core idea**: the mental model in 2–4 sentences.
2. **Key concepts**: 3–6 bullets, each one line with the "why", not just the "what".
3. **Common misconceptions**: 2–3 bullets.
4. **Check yourself**: 3 retrieval questions (no answers).
5. **Where to go deeper**: which provided resources to use for what.

Cite the provided resources inline as [1], [2] … using their numbers. Only cite provided resources. If none are provided, write the primer without citations and say "No curated sources yet" under Where to go deeper.
