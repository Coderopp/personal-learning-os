# Upload to Coderopp/personal-learning-os

```bash
cd personal-learning-os
git init
git branch -M main
git add .
git commit -m "feat: bootstrap Personal Learning OS v1"
git remote add origin https://github.com/Coderopp/personal-learning-os.git
git push -u origin main
```

Then enable GitHub Pages for the repository. The included workflow deploys the Vite build through GitHub Actions.
